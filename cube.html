Attractor Cube

A personal project

The goal of this project was to learn how to build a parametric attractor script in Grasshopper. That script was then used for formfinding to create a concrete sculpture

1. Formfinding process

drag / hover to rotate

A wavy curve was drawn around the five outer faces of a cube, which were then deconstructed to create the Grasshopper script using the surfaces as a grid and the curves as the attractor.

move across to reveal
drag / hover to rotate

The baked surfaces were then reassembled inwards so that a boolean difference can get the negative of that shape, resulting in the final cube geometry.

drag / hover to rotate

2. Mold Making + Casting

2.1 Attempt #1: PLA mold

After two failed attempts at casting this design I learnt that PLA molds are not great at capturing fine details, so I decided to make a silicone mold.

2.2 Attempt #2: Silicone mold

The silicone mold worked perfectly and captured all the details I wanted.
